CTS privacy policy

Last updated: 3 November 2026.

CTS is a personal tool used only by its author, Evgeny Varov, on his own computer. It is not offered to anyone else.

What data it accesses

With the author's consent, CTS reads the author's own Gmail mailbox through the Gmail API using the read-only scope https://www.googleapis.com/auth/gmail.readonly. It cannot send, delete or modify emails.

How the data is used

CTS looks only at job-related emails (job alerts, replies from companies and recruiters) and extracts fields such as company, job title, link and status. Nothing else is used.

Storage and sharing

  • Data stays on the author's computer. Access tokens are kept in the macOS Keychain.
  • Data is not sold, shared or used for advertising.
  • Some job-related email text may be processed by an AI model (Anthropic) solely to classify the email for the author.

Google API Services User Data Policy

CTS's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Local data can be deleted by the author at any time.
